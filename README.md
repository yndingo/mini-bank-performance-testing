# Mini-bank: deployment, monitoring and performance testing

Отчетный проект мини-банка на Java Spring Boot и PostgreSQL:
развёртывание в Docker Compose, мониторинг Prometheus/Grafana
и нагрузочное тестирование JMeter.

## Текущий статус

- Приложение развёрнуто на Ubuntu в Docker Compose.
- Настроен сбор метрик приложения, PostgreSQL и контейнеров.
- Настроен экспорт метрик JMeter в Prometheus.
- Проверен сценарий чтения счетов и операций.
- Выполнены диагностические нагрузочные прогоны.
- Выполняется трёхступенчатый тест поиска производительности.
- Подтверждающий тест будет выполнен после анализа результатов.

## Область нагрузочного тестирования

Текущий сценарий состоит из двух последовательных запросов:

1. GET /api/accounts
2. GET /api/accounts/${accountId}/operations

Используется заранее полученный токен одного банковского клиента.
Потоки JMeter не представляют разных зарегистрированных клиентов.

Результаты этого сценария не являются оценкой производительности
регистрации, авторизации, переводов и платежей.
