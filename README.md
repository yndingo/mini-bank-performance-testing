# Mini-bank: deployment, monitoring and performance testing

Отчетный проект мини-банка на Java Spring Boot и PostgreSQL.

Репозиторий содержит приложение, конфигурацию Docker Compose,
мониторинг Prometheus/Grafana, Postman-коллекцию и сценарии JMeter.

## Состав проекта

- Java app/ — исходный код приложения.
- compose.yaml — запуск стенда.
- monitoring/ — конфигурация мониторинга и дашборды.
- postman/ — функциональная проверка API.
- jmeter/ — нагрузочный сценарий и настройки генератора.
- docs/ — развёртывание, методика и результаты тестирования.

## Текущий статус

- Приложение развёрнуто на Ubuntu в Docker Compose.
- Настроен мониторинг приложения, PostgreSQL и контейнеров.
- Настроен сбор метрик JMeter в Prometheus.
- Проверен сценарий чтения счетов и операций.
- Выполнены диагностические нагрузочные прогоны.
- Выполняется трёхступенчатый тест поиска производительности.
- Подтверждающий тест будет выполнен после анализа результатов.
