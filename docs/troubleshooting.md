## Исчерпание исходящих портов генератора

Симптомы:
- java.net.BindException: Address already in use: connect;
- рост TIME_WAIT примерно до 14 тысяч;
- отказ новых соединений примерно через минуту нагрузки.

Изменения:
- явно выбран HTTP implementation HttpClient4;
- оставлен включённым Use KeepAlive;
- добавлено свойство:
  httpclient.reset_state_on_thread_group_iteration=false.

Проверка:
- около 200 Established;
- TIME_WAIT не растёт прежним темпом;
- повторный прогон выполнен без зарегистрированных ошибок.

Ограничение вывода:
изменения применены вместе, поэтому вклад каждого из них
отдельно не измерялся.
