## Исчерпание исходящих портов генератора

Симптомы:
- java.net.BindException: Address already in use: connect;
- рост TIME_WAIT примерно до 14 тысяч;
- отказ новых соединений примерно через минуту нагрузки.

Изменения:
- явно выбран HTTP implementation HttpClient4;
- оставлен включённым Use KeepAlive;
- добавлено свойство:
  httpclient.reset_state_on_thread_group_iteration=false.

Проверка:
- около 200 Established;
- TIME_WAIT не растёт прежним темпом;
- повторный прогон выполнен без зарегистрированных ошибок.

Ограничение вывода:
изменения применены вместе, поэтому вклад каждого из них
отдельно не измерялся.

## Истечение срока действия токена во время нагрузочного теста

Нагрузочный сценарий использует заранее полученный Bearer-токен.
Автоматическое обновление авторизации в текущей версии сценария
не реализовано.

Во время трёхступенчатого прогона срок действия токена истёк,
после чего появились ошибки авторизации. Токен был обновлён
в локальной конфигурации генератора.

Прогон не используется как завершённый тест поиска
производительности: после потери авторизации запросы
не выполняют тот же полезный сценарий.

Для повторного запуска задаются:
- актуальный токен;
- новый runId;
- новый файл результатов.

До повторного запуска необходимо проверить, что оставшегося
срока действия токена достаточно для всего теста.
