## Дополнения к стандартным дашбордам

- HTTP-метрики приложения: частота запросов, ошибки и время ответа.
- JMeter: активные потоки, HTTP RPS, ошибки и p95.
- Утилизация CPU и working set памяти контейнеров приложения и БД.
- Доля периодов CPU-троттлинга и скорость накопления времени троттлинга.
- Сессии PostgreSQL по состояниям.
- Статистика checkpoint PostgreSQL 17 через pg_stat_checkpointer.
