# Postman

Коллекция для ручной проверки API мини-банка.

## Файл

[vtb minibank.postman_collection.json](vtb%20minibank.postman_collection.json)

## Использование

1. Импортировать коллекцию в Postman.
2. Проверить базовый адрес запросов.
3. При удалённом стенде открыть HTTP SSH-туннель.
4. Выполнить авторизацию.
5. Подставить актуальные идентификаторы и токен
   в последующие запросы согласно их контрактам.

Для текущего стенда локальный адрес приложения:

http://127.0.0.1:8080

## Безопасность

Действующие токены и реальные персональные данные
не должны сохраняться в экспортируемой коллекции.
