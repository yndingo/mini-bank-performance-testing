## Нагрузочный сценарий

1. Получить список счетов: GET /api/accounts.
2. Извлечь accountId из ответа.
3. Получить операции выбранного счёта:
   GET /api/accounts/${accountId}/operations.

Запросы объединены в Transaction Controller.
Проверки ответов выполняются assertions.

В текущем сценарии используется заранее полученный токен.
Автоматизация авторизации и распределение нагрузки между
разными банковскими клиентами в этот сценарий не включены.

для настройки генератора нагрузки на windows в user.properties применил настройку для переиспользования текущего соединения
httpclient.reset_state_on_thread_group_iteration=false
